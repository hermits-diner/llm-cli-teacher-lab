# 1교시 첫 만남

<p className="lead">검은 창에서 AI에게 말을 걸고, AI가 내 컴퓨터에서 일하는 방식을 익힙니다. 10분.</p>

## 챗봇과 무엇이 다른가요

| | 웹 챗봇 (ChatGPT, Gemini 웹) | LLM CLI (오늘 쓰는 도구) |
| --- | --- | --- |
| 일하는 곳 | 브라우저 대화창 | 내 컴퓨터의 폴더 |
| 결과 | 답을 글로 보여 줌. 파일은 내가 복사해서 만듦 | 파일을 **직접** 만들고 고침 |
| 할 수 있는 일 | 대화 | 대화 + 파일 읽기·쓰기 + 명령 실행 |
| 내가 할 일 | 복사·붙여넣기 | 무엇을 하려는지 **읽고 허락하기** |

LLM CLI가 처음이라면 [LLM CLI 알아보기](/intro) 를 먼저 읽어 보세요. 5분이면 됩니다.

AI가 직접 파일을 만들기 때문에, 중요한 행동 전에는 **허락을 구합니다**. 이 허락 질문을 읽는 법이 오늘 배울 가장 중요한 기술입니다.

## 시작하기

<Steps>

<Step id="start-run" title="실습 폴더에서 도구 실행하기">

바탕화면의 `ai-lab` 폴더를 열고 아래 파일을 더블클릭합니다.

<ForTool tool="agy">`start-agy.cmd`</ForTool>
<ForTool tool="codex">`start-codex.cmd`</ForTool>
<ForTool tool="claude">`start-claude.cmd`</ForTool>

cmd 창에서 실행해도 됩니다. `ai-lab` 폴더 위쪽 주소창에 `cmd` 를 입력하고 <kbd>Enter</kbd> 를 누르면 이 폴더에서 cmd 창이 열립니다.

<ForTool tool="agy">

```cmd
start-agy
```

</ForTool>
<ForTool tool="codex">

```cmd
start-codex
```

</ForTool>
<ForTool tool="claude">

```cmd
start-claude
```

</ForTool>

</Step>

<Step id="start-hello" title="말 걸기">

이 페이지의 문장을 **복사해서 붙여넣는 것** 이 가장 확실합니다. 검은 창에서 한글을 직접 치면 마지막 글자가 사라지거나 다음 줄로 밀리는 경우가 있습니다.

<Prompt>{prompts.hello}</Prompt>

<ForTool tool="claude">

직접 칠 때는 문장 끝에서 <kbd>Space</kbd> 를 한 번 누른 뒤 <kbd>Enter</kbd> 를 누르세요. 마지막 글자가 밀리는 문제를 피할 수 있습니다.

</ForTool>

</Step>

<Step id="start-approve" title="허락 질문 읽어 보기">

AI가 파일을 만들거나 명령을 실행하기 전에 이런 질문을 합니다. 모양은 도구마다 조금 다릅니다.

```screen
 Allow this command?
   node tools/hwpx-fill.mjs --list mission2/notice-form.hwpx

 > 1. Yes
   2. Yes, and don't ask again for this command
   3. No, and tell the AI what to do differently
```

- **무엇을 하려는지** 한 줄로 읽습니다. 이 예시는 "양식의 빈칸 목록을 본다" 는 뜻입니다.
- 이해가 되면 **Yes** 를 고릅니다. 화살표 키로 고르고 <kbd>Enter</kbd> 를 누릅니다.
- 모르겠으면 **No** 를 고르고 "이게 무슨 뜻이야?" 라고 물어보세요. AI가 설명해 줍니다.
- 실습 폴더(바탕화면의 `ai-lab`) 밖의 파일을 지우거나 바꾸려 하면 **No** 를 고르세요.

</Step>

</Steps>

## 알아 두면 좋은 키와 명령

입력창에 `/` 로 시작하는 명령을 치면 도구의 기능을 쓸 수 있습니다.

<ForTool tool="agy">

| 하고 싶은 일 | 입력 |
| --- | --- |
| 도움말 보기 | `/help` |
| 대화 새로 시작 | `/clear` |
| 남은 사용량 보기 | `/usage` |
| 허락 규칙 보기·바꾸기 | `/permissions` |
| 끝내기 | `/exit` |
| 작업 방식 바꾸기 (기본 → 수정 자동 허락 → 계획만) | <kbd>Shift</kbd>+<kbd>Tab</kbd> |

</ForTool>

<ForTool tool="codex">

| 하고 싶은 일 | 입력 |
| --- | --- |
| 대화 새로 시작 | `/new` |
| 계정·사용량 상태 보기 | `/status` |
| 허락 방식 바꾸기 | `/permissions` |
| 끝내기 | `/quit` |

</ForTool>

<ForTool tool="claude">

| 하고 싶은 일 | 입력 |
| --- | --- |
| 도움말 보기 | `/help` |
| 대화 새로 시작 | `/clear` |
| 남은 사용량 보기 | `/usage` |
| 허락 규칙 보기·바꾸기 | `/permissions` |
| 끝내기 | `/exit` |
| 작업 방식 바꾸기 (자동 → 매번 묻기 → 수정 자동 허락 → 계획만) | <kbd>Shift</kbd>+<kbd>Tab</kbd> |

</ForTool>

AI가 일하는 도중에 멈추고 싶으면 <kbd>Esc</kbd> 를 누릅니다.

## 지켜 주세요

<Callout kind="warn" title="학생 개인정보는 넣지 않습니다">
AI에게 보낸 글과 파일 내용은 회사 서버로 전송됩니다. 학생 이름·연락처·성적이 든 파일은 실습 폴더에 넣지 말고, 예시가 필요하면 가상의 데이터를 쓰세요.
</Callout>

- 허락 질문은 **읽고** 고릅니다. 습관처럼 Yes를 누르지 않습니다.
- AI가 만든 결과는 **사람이 확인한 뒤** 씁니다. 날짜·요일·숫자는 특히 다시 봅니다.
- 실습은 바탕화면의 `ai-lab` 폴더 안에서만 합니다. 실습 폴더의 `AGENTS.md` 에도 같은 규칙이 적혀 있어 AI가 함께 지킵니다.
