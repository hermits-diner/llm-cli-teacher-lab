# LLM CLI 알아보기

<p className="lead">연수에서 쓰는 도구가 무엇이고 어떻게 일하는지 먼저 알아봅니다. 코딩을 몰라도 읽을 수 있습니다. 5분.</p>

## 한 문장으로

**LLM CLI는 명령 프롬프트(검은 창)에서 실행하는 AI 비서입니다.** 말로 부탁하면 내 컴퓨터의 폴더 안에서 파일을 직접 읽고, 만들고, 고칩니다.

## 이름 풀이

| 말 | 원래 이름 | 쉽게 말하면 |
| --- | --- | --- |
| **LLM** | Large Language Model (대규모 언어 모델) | ChatGPT·Gemini·Claude 같은 AI의 '두뇌'. 글을 읽고 씁니다 |
| **CLI** | Command Line Interface (명령줄 인터페이스) | 마우스 대신 글자를 입력해 컴퓨터를 다루는 방식. Windows의 **명령 프롬프트(cmd)** 가 그 창입니다 |

둘을 합치면 "검은 창에서 쓰는 AI" 입니다. 명령어를 외울 필요는 없습니다. 검은 창에서 도구를 한 번 실행하고 나면, 그다음부터는 **평소 말투로** 부탁합니다.

## 웹 챗봇과 무엇이 다른가요

가정통신문을 만든다고 해 보겠습니다.

**웹 챗봇으로 하면**

1. 메모 내용을 대화창에 붙여넣고 문장을 써 달라고 합니다.
2. AI가 쓴 글을 복사합니다.
3. 한글 양식을 열고 칸마다 붙여넣습니다. 칸이 많으면 여러 번 반복합니다.

**LLM CLI로 하면**

1. "메모를 읽고 가정통신문 양식을 채워 줘" 라고 부탁합니다.
2. AI가 메모와 양식 파일을 직접 열어 보고, 칸을 채운 새 파일을 만듭니다.
3. 나는 허락 질문에 답하고, 완성된 파일을 열어 검토합니다.

복사·붙여넣기처럼 사람이 손으로 하던 일을 AI가 맡고, 사람은 **부탁하고 확인하는 일** 에 집중합니다. 한눈에 보는 비교표는 [1교시](/start) 에 있습니다.

## AI가 일하는 순서

```screen
 나  > 이번 주 알림을 담은 학급 안내 웹페이지를 만들어 줘

 AI  ● 폴더를 살펴보고 AGENTS.md 지침을 읽었습니다.
 AI  ● mission1/site/index.html 파일을 만들려고 합니다. 허락할까요?
       > 1. Yes
         2. No

 AI  ● 파일을 만들었습니다. 브라우저로 열어 확인해 보세요.
```

화면은 예시입니다. 실제 문구는 도구마다 조금 다릅니다.

1. **살펴보기**: 폴더에 어떤 파일이 있는지, 지침 파일에 무엇이 적혀 있는지 읽습니다.
2. **계획하기**: 부탁을 이루려면 무엇을 해야 할지 정합니다.
3. **허락 받기**: 파일을 만들거나 명령을 실행하기 전에 물어봅니다.
4. **실행하기**: 파일을 쓰고, 필요한 프로그램을 실행합니다.
5. **확인하고 알리기**: 결과를 스스로 점검하고, 무엇을 했는지 알려 줍니다.

마음에 들지 않으면 "제목을 더 크게 해 줘" 처럼 말로 고쳐 달라고 하면 됩니다. 이 **부탁 → 허락 → 확인 → 고치기** 의 반복이 오늘 실습의 전부입니다.

## 오늘 쓰는 세 도구

| 도구 | 만든 회사 | 필요한 계정 | 비용 |
| --- | --- | --- | --- |
| Antigravity CLI | Google | 개인 Gmail | 무료로 시작 (주간 사용량 한도) |
| Codex CLI | OpenAI | ChatGPT | ChatGPT 유료 요금제(Plus 이상) |
| Claude Code | Anthropic | Claude | Claude Pro 이상 (무료 요금제 불가) |

셋 다 하는 일과 쓰는 방법은 거의 같습니다. 이미 쓰고 있는 구독을 기준으로 하나만 고르면 됩니다. 페이지 맨 위 **내 도구** 에서 고르면 이 사이트의 설명이 그 도구에 맞게 바뀝니다.

## 잘하는 일과 조심할 일

**잘하는 일**

- 메모를 정리해 안내문·회의록 문장으로 쓰기
- 한글 양식(.hwpx)의 빈칸 채우기
- 웹페이지, 퀴즈, 수업 타이머 같은 작은 프로그램 만들기
- 여러 파일을 한꺼번에 정리하거나 형식 바꾸기

**조심할 일**

- **틀릴 수 있습니다.** 날짜·요일·숫자·이름을 그럴듯하게 틀리기도 합니다. 결과는 사람이 꼭 확인합니다.
- **보낸 내용은 회사 서버로 전송됩니다.** 학생 이름·연락처·성적·상담 내용은 넣지 않습니다. 예시가 필요하면 가상의 데이터를 씁니다.
- **사용량 한도가 있습니다.** 한도가 차면 다음 충전까지 기다려야 합니다.
- **허락 질문은 읽고 답합니다.** 무슨 일인지 모르겠으면 No를 고르고 "이게 무슨 뜻이야?" 라고 물어보세요.

## 안전하게 쓰도록 돕는 장치

- **작업 폴더**: AI는 도구를 실행한 폴더를 작업 공간으로 삼습니다. 연수에서는 바탕화면의 `ai-lab` 폴더에서만 실습합니다.
- **허락 질문**: 파일을 바꾸거나 명령을 실행하기 전에 물어봅니다. 얼마나 자주 물어볼지는 도구 안에서 바꿀 수 있습니다.
- **지침 파일 `AGENTS.md`**: AI가 일을 시작할 때마다 읽는 업무 지침서입니다. 실습 폴더에는 "쉬운 말로 답하기", "개인정보를 만들거나 묻지 않기" 같은 규칙이 미리 적혀 있습니다. [4교시](/wrap-up) 에서 내 규칙을 더하는 법을 배웁니다.

## 알아 두면 좋은 낱말

| 낱말 | 뜻 |
| --- | --- |
| 명령 프롬프트(cmd) | Windows에 들어 있는 검은 창. 글자로 명령을 입력합니다 |
| 프롬프트 | AI에게 하는 부탁의 글. 구체적일수록 결과가 정확합니다 |
| 경로 | 파일이 있는 위치를 적은 주소. 예: `ai-lab\mission1\site` |
| PATH | 명령을 입력했을 때 Windows가 프로그램을 찾아보는 폴더 목록. 설치 프로그램이 AI 도구를 여기에 등록해 어느 폴더에서든 실행되게 합니다 |
| Node.js | 한글 양식 채우기 같은 실습 도구를 실행하는 프로그램. 설치 프로그램이 함께 준비합니다 |
| 사용량 한도 | 일정 기간에 쓸 수 있는 양. 요금제마다 다릅니다 |
