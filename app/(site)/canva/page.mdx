# 부록: Canva 연결해 슬라이드 만들기

<p className="lead">AI와 Canva를 연결(MCP)하면 말로 Canva 디자인을 만들고 고칠 수 있습니다. 연수 실습에는 넣지 않은 참고 자료입니다.</p>

<Callout kind="warn" title="자동 승인 실행 파일에서는 연결하지 않기">
연수용 `start-…cmd` 는 AI가 묻지 않고 일하는 설정입니다. Canva를 연결하면 AI가 묻지 않고 디자인을 만들고 고칠 수 있습니다. 내 업무 폴더에서 검은 창에 `agy`·`codex`·`claude` 만 입력해 **허락을 묻는 방식** 으로 켠 뒤 쓰세요.
</Callout>

## 연결하는 방법

Canva 무료·교육용 계정 모두 연결할 수 있습니다. 연결할 때 인터넷 창에서 Canva에 로그인하고 허락합니다.

<ForTool tool="claude">

**claude.ai 커넥터로 연결 (이 사이트에서 확인한 방법)**

1. [claude.ai](https://claude.ai) 의 설정 → 커넥터에서 **Canva** 를 추가합니다.
2. Claude Code 입력창에 `/mcp` 를 입력하고 **claude.ai Canva** 를 고릅니다.
3. 인터넷 창에서 Canva에 로그인하고 허락합니다. "Authentication successful" 이 나오면 됩니다.

**플러그인으로 연결 (Canva 공식 안내, 직접 확인하지 못함)**

Claude Code 입력창에 한 줄씩 입력합니다.

```
/plugin marketplace add canva-sdks/canva-skills
/plugin install canva@canva-skills
```

</ForTool>
<ForTool tool="codex">

**플러그인으로 연결 (Canva 공식 안내, 직접 확인하지 못함)**

검은 창(cmd)에서 차례로 실행합니다.

```cmd
codex plugin marketplace add canva-sdks/canva-skills
codex plugin add canva@canva-skills
codex mcp login canva
```

</ForTool>
<ForTool tool="agy">

Antigravity CLI에서 Canva를 연결하는 공식 방법은 아직 확인하지 못했습니다. Canva를 쓰려면 Claude Code나 ChatGPT·Claude·Gemini 앱의 Canva 연결 기능을 쓰세요.

</ForTool>

## 어느 계정에 연결됐는지 확인하기

AI 로그인과 Canva 로그인은 **따로** 입니다. 인터넷 창에 개인 Canva로 로그인되어 있으면 학교 Canva가 아니라 개인 Canva가 연결됩니다. 연결하자마자 확인합니다.

```prompt
내 Canva에서 최근에 고친 디자인 3개의 제목을 보여 줘.
```

- 내가 아는 디자인이 나오면 맞게 연결된 것입니다.
- 학교(교육용) Canva는 관리자가 이 연결 기능을 꺼 두었을 수 있습니다.

## 슬라이드 만들기

```prompt
Canva로 학부모 설명회에서 쓸 발표 슬라이드 5장을 만들어 줘. 주제는 '우리 반 생성형 AI 활용 수업 안내'. 1) 왜 수업에서 AI를 쓰나요 2) 수업에서 이렇게 씁니다 3) 개인정보는 이렇게 지킵니다 4) 가정에서 도와주세요 5) 문의. 모든 글은 한국어로, 학부모가 이해하기 쉬운 공손한 말투. 깔끔하고 밝은 스타일, 글자는 크게.
```

**20초 안팎** 이면 사진과 배치까지 들어간 슬라이드가 Canva에 생기고, AI가 링크를 알려 줍니다.

## 꼭 읽어 보고 고치기

Canva가 문장을 다듬으면서 **한글 오타를 만들 수 있습니다.** 이 사이트를 만들며 시험했을 때 실제로 이런 일이 있었습니다.

| 부탁한 글 | Canva가 넣은 글 |
| --- | --- |
| 이름·연락처 등 개인정보는 | 이름:연락처 등 **게인정보** 는 |
| 올바르게 | **올바로게** |

모든 슬라이드를 읽어 보고, 틀린 곳을 말로 고칩니다.

```prompt
3번 슬라이드의 '게인정보'를 '개인정보'로, 4번 슬라이드의 '올바로게'를 '올바르게'로 고쳐 줘.
```

Canva는 고친 결과를 **미리보기로 보여 주고 허락을 받은 뒤에** 저장합니다. 미리보기를 확인하고 "저장해 줘" 라고 답합니다.

## PowerPoint 파일로 받기

```prompt
이 디자인을 PowerPoint(pptx) 파일로 내보내 줘.
```

AI가 내려받기 링크를 알려 줍니다. PDF·PNG로도 받을 수 있습니다.

## 플러그인이란

**플러그인** 은 스킬과 MCP 연결 등을 하나로 묶은 꾸러미입니다. 예를 들어 Canva 플러그인 하나를 설치하면 Canva 연결(MCP)과 디자인 고치기·피드백 받기·크기 바꾸기 같은 Canva 작업 요령(스킬 여러 개)이 한꺼번에 들어옵니다.

| 도구 | 플러그인 관리 |
| --- | --- |
| Antigravity CLI | 대화창에서 `/plugin`, 검은 창에서 `agy plugin list` |
| Codex CLI | 대화창에서 `/plugins`, 검은 창에서 `codex plugin list` |
| Claude Code | 대화창에서 `/plugin` |

<Callout kind="warn" title="믿을 수 있는 플러그인만">
플러그인은 선생님 컴퓨터에서 선생님 권한으로 프로그램을 실행할 수 있습니다. 서비스 회사가 직접 낸 공식 플러그인처럼 출처가 분명한 것만 설치하세요.
</Callout>
