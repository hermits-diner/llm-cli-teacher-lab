# LLM CLI 알아보기

<p className="lead">오늘 쓰는 도구가 무엇인지 알아봅니다.</p>

<PagePhoto id="intro" />

## 한 줄 요약

**검은 창에서 말로 부탁하면, 내 컴퓨터 폴더에 파일을 직접 만들어 주는 AI 비서** 입니다.

| 이름 | 뜻 |
| --- | --- |
| **LLM** | ChatGPT·Gemini·Claude 같은 AI의 두뇌 |
| **CLI** | 마우스 대신 글자로 컴퓨터에 일을 시키는 검은 창(명령 프롬프트) |

명령어는 외우지 않습니다. 켜고 나면 **평소 말투로** 부탁합니다.

## 챗봇과 다른 점

가정통신문을 만든다면 이렇게 다릅니다.

| | 웹 챗봇 | LLM CLI |
| --- | --- | --- |
| 선생님이 할 일 | 메모 붙여넣기 → 답 복사 → 한글 칸마다 붙여넣기 | "메모로 양식 채워 줘" 한 줄 |
| 남는 것 | 대화창의 글 | 완성된 한글 파일 |

손이 가던 일은 AI가 하고, 선생님은 **부탁하고 검토** 합니다.

## 에이전트 코딩(바이브 코딩)의 순서

**바이브 코딩**은 코드를 직접 쓰지 않고, 원하는 결과를 말로 설명해 AI가 코드를 쓰게 하는 방식입니다. 오늘 도구처럼 AI가 파일을 만들고 실행까지 하면 **에이전트 코딩** 이라고 부릅니다.

<AgentFlow />

**코드는 AI가 씁니다.** 선생님은 무엇을 원하는지 말하고, 결과가 맞는지 판단합니다.

## 실제 화면으로 보면

```screen
 나  > 이번 주 알림을 담은 학급 안내 웹페이지를 만들어 줘

 AI  ● 폴더를 살펴보고 업무 지침서(AGENTS.md)를 읽었습니다.
 AI  ● mission1/site/index.html 파일을 만들겠습니다.
 AI  ● 파일을 만들었습니다. 열어서 확인해 보세요.
```

**부탁 → 확인 → 고치기.** 이 반복이 오늘 실습의 전부입니다. 연수에서는 AI가 허락을 묻지 않고 바로 일하도록 켜 둡니다.

## 지침서, 스킬, MCP, 플러그인

AI에게 일을 가르치고 도구를 쥐여 주는 방법입니다. 세 도구 모두 지원합니다.

| | 업무 지침서 | 스킬 | MCP | 플러그인 |
| --- | --- | --- | --- | --- |
| 비유 | 늘 지키는 업무 규칙 | 특정 일의 작업 요령서 | 바깥 서비스와 잇는 연결선 | 요령서와 연결선을 묶은 꾸러미 |
| 정체 | `AGENTS.md` 파일 하나 | 폴더 하나(`SKILL.md` 와 도구) | 구글 드라이브, 노션, 캔바 같은 서비스와의 연결 | 스킬·MCP 등을 한 번에 설치하는 묶음 |
| AI가 읽는 때 | 일을 시작할 때마다 | 그 일이 필요할 때만 | 그 서비스의 자료가 필요할 때 | 안에 든 스킬·MCP가 각각 동작 |
| 오늘 실습 | 실습 폴더에 있음 | 문서 작업의 `hwpx`, 슬라이드 제작의 디자인 스킬 `frontend-design` 을 직접 설치 | 쓰지 않음 ([부록](/mcp)) | 쓰지 않음 ([부록](/canva)) |

<More title="스킬, MCP, 플러그인 자세히">

**스킬**
- AI에게 "스킬 설치해 줘"라고 부탁하면 설치합니다. 오늘은 **전역**(내 컴퓨터 전체)으로 설치해서, 연수 뒤 다른 폴더에서도 씁니다.
- 전역 스킬 폴더: Codex는 `사용자 폴더\.agents\skills`, Claude Code는 `사용자 폴더\.claude\skills`. Antigravity는 원래 `사용자 폴더\.gemini\config\skills` 를 읽는데, 설치 프로그램이 `.agents\skills` 도 읽도록 등록해 둡니다. 한 폴더에서만 쓰려면 그 폴더의 `.agents\skills` (Claude Code는 `.claude\skills`) 에 둡니다.
- 지침서는 매번 통째로 읽지만, 스킬은 이름과 한 줄 설명만 기억해 두었다가 그 일이 생기면 펼쳐 봅니다. 그래서 요령이 길어도 부담이 없습니다.
- 스킬은 내 권한으로 프로그램을 실행합니다. 믿을 수 있는 곳의 스킬만 설치합니다.
- 잘 된 작업은 스킬로 남겨 둘 수 있습니다. 예: "방금 가정통신문 채운 순서를 스킬로 만들어 줘"

**플러그인**
- 스킬·MCP 연결 등을 묶어 한 번에 설치하는 꾸러미입니다. 예: Canva 플러그인 = Canva 연결 + Canva 작업 요령 여러 개
- 대화창에서 Antigravity·Claude Code는 `/plugin`, Codex는 `/plugins` 로 둘러보고 설치합니다.
- 플러그인도 내 권한으로 프로그램을 실행할 수 있으니 출처가 분명한 것만 설치합니다.

**MCP** (Model Context Protocol)
- AI가 내 컴퓨터 밖의 서비스를 직접 읽고 쓰게 해 주는 표준 연결 방식입니다. 서비스마다 로그인과 허락이 필요합니다.
- 각 도구의 `mcp` 명령(`agy mcp`, `codex mcp`, `claude mcp`)으로 연결하고 뺍니다. 따라 하기는 [부록: MCP로 바깥 서비스 연결하기](/mcp) 에 있습니다.
- **연수용 실행 파일은 자동 승인이므로 MCP를 연결하지 않습니다.** 연결하면 AI가 묻지 않고 메일을 보내거나 문서를 고칠 수 있습니다. 학생 정보가 있는 서비스는 평소에도 연결하지 않습니다.

</More>

## 꼭 지킬 것

- **학생 개인정보는 넣지 않습니다.** 보낸 내용은 회사 서버로 갑니다.
- **결과는 사람이 검토합니다.** 날짜·요일·숫자를 그럴듯하게 틀리기도 합니다.
- **AI가 하는 일을 지켜봅니다.** 이상하면 <kbd>Esc</kbd> 로 멈추고 "그거 하지 말고 …해 줘" 라고 말합니다.

<More title="안전장치와 사용 한도">

- **작업 폴더**: AI는 도구를 켠 폴더에서 일합니다. 연수에서는 바탕화면의 `ai-lab` 폴더입니다.
- **자동 승인**: 연수용 실행 파일(`start-…cmd`)은 시간을 아끼려고 AI가 매번 허락을 묻지 않게 켜 둡니다. 그만큼 AI가 폴더 밖을 건드릴 수도 있으므로, 업무 지침서에 "이 폴더 밖은 건드리지 않기, 지우기 전에는 묻기"를 적어 두었습니다.
- **업무 지침서(`AGENTS.md`)**: AI가 일을 시작할 때마다 읽는 파일입니다. "쉬운 말로 답하기", "개인정보 다루지 않기" 같은 규칙이 미리 적혀 있고, [나누고 마무리](/wrap-up) 에서 내 규칙을 더합니다.
- **사용 한도**: 요금제마다 쓸 수 있는 양이 정해져 있습니다. 다 쓰면 다음 충전까지 기다립니다.
- AI 두뇌는 `/model` 로 바꿀 수 있지만 연수에서는 기본값 그대로 씁니다. 자세한 내용은 [도구별 명령어](/commands) 에 있습니다.

</More>

<More title="알아 두면 좋은 낱말">

| 낱말 | 뜻 |
| --- | --- |
| 명령 프롬프트(cmd) | Windows에 들어 있는 검은 창 |
| 프롬프트 | AI에게 하는 부탁의 글. 구체적일수록 결과가 좋습니다 |
| 경로 | 파일이 있는 위치. 예: `ai-lab\mission1\site` |
| PATH | 컴퓨터의 "프로그램 주소록". 여기에 등록되면 어느 폴더에서든 이름만 쳐서 실행됩니다 |
| Node.js | 문서 작업 같은 실습 도구를 돌리는 프로그램. 설치 프로그램이 함께 깔아 줍니다 |

</More>
