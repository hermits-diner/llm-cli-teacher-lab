## 나만의 업무 지침서

`AGENTS.md` 는 AI가 일을 시작할 때마다 읽는 **업무 지침서** 입니다. 내 규칙을 적어 두면 매번 말하지 않아도 지킵니다.

```prompt
AGENTS.md 맨 아래에 '우리 학교 문서 규칙' 항목을 만들고 이렇게 적어 줘: 학교 이름은 가상중학교, 날짜는 '2026. 11. 12.(목)' 형식, 문장은 학부모님께 드리는 공손한 말투.
```

새 폴더에 `AGENTS.md` 를 두면 그 폴더가 나만의 업무 공간이 됩니다. `AGENTS.md` 는 **여러 AI 도구가 함께 읽는 공통 지침 파일** 이라, 도구를 바꿔도 규칙을 다시 쓸 필요가 없습니다.

<More title="도구마다 다른 지침 파일">

| 도구 | 읽는 파일 | `AGENTS.md` 만 있을 때 |
| --- | --- | --- |
| Antigravity CLI | `AGENTS.md`, `GEMINI.md` | 읽음 |
| Codex CLI | `AGENTS.md` | 읽음 |
| Claude Code | `CLAUDE.md` | 읽음 (`CLAUDE.md` 가 없을 때) |

- 규칙은 `AGENTS.md` **한 곳에만** 씁니다. 같은 규칙을 파일 여러 개에 나눠 쓰면 고칠 때 빠뜨립니다.
- Claude Code의 `/init` 등으로 `CLAUDE.md` 가 생기면, 그 파일 맨 위에 `@AGENTS.md` 한 줄을 넣습니다. 그래야 Claude도 같은 규칙을 계속 읽습니다. 실습 폴더의 `CLAUDE.md` 가 바로 이 한 줄입니다.
- 모든 폴더에 적용할 규칙(예: 항상 존댓말로 답하기)은 도구별 전체 설정 파일에 둡니다. 위치는 [도구별 명령어](/commands) 에 있습니다.

</More>

## 내일 해 볼 만한 일

- 단원 복습 퀴즈 웹페이지
- 행사 안내 페이지를 만들어 학부모 단톡방에 주소 공유
- 회의 메모를 회의록 양식(.hwpx)에 정리
- 수업 타이머, 발표 순서 뽑기 같은 교실 도구

형식별 부탁 문장은 [만들 수 있는 파일과 부탁 예시](/files), 도구 명령은 [도구별 명령어](/commands) 에 있습니다.

<More title="다음 단계: 고칠 때마다 자동으로 게시하기 (GitHub + Vercel)">

오늘은 폴더를 끌어다 놓아 올렸습니다. 2교시에 만든 Vercel 프로젝트에 GitHub 저장소를 연결해 두면, AI에게 **"고치고 깃허브에 올려 줘"** 한마디로 같은 주소에 새 버전이 게시됩니다.

1. [github.com](https://github.com) 에 **개인 계정**으로 가입합니다. 학교·단체(조직) 계정의 저장소는 Vercel 무료 요금제에 연결할 수 없습니다.
2. [git-scm.com](https://git-scm.com) 에서 Git을 설치합니다. 처음 올릴 때 인터넷 창이 열리면 GitHub에 로그인합니다.
3. GitHub에서 빈 저장소를 하나 만들고, 페이지 폴더(예: `mission1\site`)에서 AI에게 부탁합니다.

```prompt
이 폴더를 https://github.com/내아이디/class-notice 저장소에 올려 줘. 처음이면 git 설정부터 해 줘.
```

4. [vercel.com](https://vercel.com) 에서 2교시에 만든 프로젝트를 열고 **Connect Git** 을 눌러 그 저장소를 연결합니다. 주소는 2교시 그대로입니다. 저장소 이름은 영문·숫자·하이픈으로 짓습니다.
5. 이제부터는 이렇게만 말하면 1분 안에 같은 주소에 반영됩니다.

```prompt
맨 위 알림을 이번 주 내용으로 바꾸고 깃허브에 올려 줘.
```

저장소를 공개로 만들면 페이지의 코드도 누구나 볼 수 있습니다. 학생 이름·연락처는 넣지 않습니다.

</More>

## 꼭 기억할 것

<Callout kind="warn" title="학생 개인정보는 넣지 않습니다">
보낸 내용은 회사 서버로 갑니다. 학교·교육청의 생성형 AI 사용 지침을 먼저 확인하세요.
</Callout>

- **검토는 사람이.** 날짜·숫자·이름은 다시 봅니다.
- **평소에는 허락을 묻게.** 연수용 실행 파일은 자동 승인을 켜 두었습니다. 내 업무 폴더에서는 검은 창에 `agy`·`codex`·`claude` 만 입력해 켜면 AI가 일하기 전에 허락을 묻습니다.
- **학생과 함께 쓸 때는** 서비스별 나이 제한과 약관을 확인합니다. Antigravity는 만 18세 이상입니다.
- 화면이 사이트와 다르면 AI에게 "지금 화면에서 뭘 고르면 돼?" 라고 물어보세요.

<More title="비용과 사용 한도">

무료로 시작한 도구도 사용 한도가 있습니다. 다 쓰면 다음 충전까지 기다리거나 다른 도구를 씁니다. 도구별 한도는 [도구별 명령어](/commands) 의 "쓰는 모델" 항목에 있습니다.

</More>
