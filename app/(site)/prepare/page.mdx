## 준비 순서

<Steps>

<Step id="prep-netlify" title="Netlify 가입하기">

2교시에 만든 웹페이지를 인터넷에 무료로 올려 주는 곳입니다. [app.netlify.com](https://app.netlify.com/signup) 에서 이메일로 가입합니다.

<More title="공개 설정 미리 바꾸기 (선택)">

2026년 7월 28일 이후 가입한 계정은 올린 페이지가 **비공개** 로 시작합니다. 팀 설정(Team settings) → 방문자 접근(Visitor access) → 기본 공개 범위를 **Public** 으로 바꿔 두면 편합니다. 못 찾아도 괜찮습니다. 연수 때 **Make public** 버튼을 누르면 됩니다.

</More>

</Step>

<Step id="prep-cmd" title="검은 창(cmd) 열기">

<kbd>Windows</kbd> 키 → `cmd` 입력 → **명령 프롬프트**. `C:\Users\(내 이름)>` 이 보이면 맞습니다.

<Callout kind="warn">
앞에 **PS** 가 붙어 있으면 다른 창(PowerShell)입니다. 닫고 다시 `cmd` 로 여세요.
</Callout>

</Step>

<Step id="prep-install" title="한 줄로 설치하기">

아래 줄을 복사해 검은 창에 붙여넣고(<kbd>Ctrl</kbd>+<kbd>V</kbd>) <kbd>Enter</kbd>.

<Cmd>{`curl -fsSL ${SITE_URL}/setup.bat -o "%TEMP%\\ai-lab-setup.bat" && "%TEMP%\\ai-lab-setup.bat"`}</Cmd>

영어 메뉴가 나오면 내 도구 번호를 누릅니다.

| 키 | 도구 |
| --- | --- |
| <kbd>1</kbd> | Claude Code |
| <kbd>2</kbd> | Codex CLI |
| <kbd>3</kbd> | Antigravity CLI |

나머지는 기다리면 됩니다. 끝나면 결과가 이렇게 나옵니다.

```screen
 ======================== RESULT ========================
   PC check          : OK
   Internet          : OK
   Practice folder   : OK
   Node.js           : OK v24.22.0
   Antigravity CLI   : OK 1.4.3
   PATH (any folder) : OK
 ========================================================
   All done.
```

모두 `OK` 면 성공입니다. 바탕화면에 `ai-lab` 폴더가 생기고 자동으로 열립니다. `FAIL` 이 있으면 아래쪽 오류 코드(예: `E05`)를 [막혔어요](/help) 에서 찾으세요.

<More title="설치 프로그램이 하는 일">

- 바탕화면에 실습 폴더 `ai-lab` 을 만들고, 실습 도구를 돌리는 프로그램(Node.js)과 AI 도구를 깝니다.
- AI 도구를 "프로그램 주소록(PATH)"에 등록합니다. 그래서 새 검은 창이면 어느 폴더에서든 `agy`, `codex`, `claude` 로 실행됩니다.
- 관리자 권한이 필요 없고, 내 계정 폴더와 `ai-lab` 폴더에만 설치합니다.
- <kbd>4</kbd> 를 누르면 설치 없이 이 PC에서 가능한지 점검만 합니다.
- 계속 실패하면 [직접 설치하기](/install) 의 명령으로 도구만 따로 설치할 수 있습니다.

</More>

</Step>

<Step id="prep-login" title="처음 켜고 로그인하기">

<ForTool tool="agy">

`ai-lab` 폴더의 `start-agy.cmd` 를 더블클릭합니다.

1. 로그인 방법: **Google 계정**
2. 인터넷 창이 열리면 개인 Gmail로 로그인 → 허용. 코드가 보이면 복사해 검은 창에 붙여넣기
3. 화면 테마, 약관 동의
4. "이 폴더를 믿나요?(Do you trust …)" → **예**

</ForTool>

<ForTool tool="codex">

`ai-lab` 폴더의 `start-codex.cmd` 를 더블클릭합니다.

1. 로그인 방법: **Sign in with ChatGPT**
2. 인터넷 창이 열리면 ChatGPT로 로그인 → 허용
3. "이 폴더를 믿나요?" → **trust**. 믿지 않으면 파일을 만들지 못합니다.

인터넷 창이 안 열리면 검은 창에서 `codex login --device-auth` 를 실행해 안내대로 코드를 넣으세요.

</ForTool>

<ForTool tool="claude">

`ai-lab` 폴더의 `start-claude.cmd` 를 더블클릭합니다.

1. 화면 테마
2. 로그인 방법: **Claude 구독 계정**
3. 인터넷 창이 열리면 claude.ai에 로그인 → 허용
4. "이 폴더를 믿나요?" → **Yes, I trust this folder**

</ForTool>

화면 문구는 도구가 업데이트되며 조금 바뀔 수 있습니다. 로그인하고 폴더를 믿는다고 답하면 됩니다.

</Step>

<Step id="prep-hello" title="첫 인사 보내기">

<Prompt>{prompts.hello}</Prompt>

AI가 폴더 안의 내용을 설명해 주면 준비 끝입니다.

</Step>

</Steps>

<More title="setup.bat 파일을 직접 받은 경우">

메신저나 메일로 받은 `setup.bat` 은 더블클릭해도 됩니다. 경고가 두 번 나옵니다.

1. 인터넷 창의 "일반적으로 다운로드되지 않는 파일" → **유지**
2. 파란 창 "Windows의 PC 보호" → **추가 정보** → **실행**

경고가 불안하면 위의 한 줄 설치를 쓰세요. 같은 파일이지만 경고가 나오지 않습니다.

</More>
