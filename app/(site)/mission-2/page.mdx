# 3교시 한글 양식에 가정통신문 채우기

<p className="lead">행사 메모만 주면 AI가 문장을 쓰고, 한글(.hwpx) 양식의 빈칸에 채워 새 문서를 만듭니다. 35분.</p>

<Callout kind="check" title="이번 시간에 남는 것">
내용이 채워진 `notice-result.hwpx`. 한글에서 바로 열어 인쇄할 수 있는 가정통신문입니다.
</Callout>

## 어떻게 동작하나요

양식 안에는 `{{제목}}`, `{{일시}}` 처럼 **채울 자리** 가 표시되어 있습니다.

1. AI가 메모를 읽고 자리마다 들어갈 문장을 씁니다.
2. 실습 폴더의 **양식 채우기 도구** 가 그 문장을 자리에 넣습니다. 글꼴·표·줄 간격 같은 서식은 양식 그대로 남습니다.
3. 원본 양식은 건드리지 않고 **새 파일** 로 저장합니다.

AI에게 이 순서를 알려 주는 것은 실습 폴더의 `AGENTS.md` 와 `school-hwpx` 스킬입니다. 그래서 짧게 부탁해도 같은 방법으로 일합니다.

<Steps>

<Step id="m2-look" title="양식과 메모 살펴보기">

바탕화면의 `ai-lab` 폴더에서 `mission2` 폴더를 엽니다.

| 파일 | 내용 |
| --- | --- |
| `notice-form.hwpx` | 빈 가정통신문 양식. 한글에서 열면 `{{제목}}` 같은 자리가 보입니다 |
| `notice-memo.txt` | 행사 메모(가상). 더블클릭하면 메모장으로 열립니다 |

양식을 열어 봤다면 **저장하지 말고** 닫으세요.

</Step>

<Step id="m2-fill" title="AI에게 채우기 부탁하기">

<Prompt>{prompts.m2}</Prompt>

AI는 보통 이 순서로 일합니다. 단계마다 허락을 구하면 읽고 허락하세요. **1~2분** 걸립니다.

1. `node tools/hwpx-fill.mjs --list ...` 로 양식의 빈칸 목록을 봅니다.
2. 메모를 읽고 `notice-values.json` 에 칸마다 들어갈 문장을 씁니다.
3. `node tools/hwpx-fill.mjs ...` 로 양식을 채워 `notice-result.hwpx` 를 만듭니다.
4. 결과에 빈칸이 남았는지 스스로 확인하고 알려 줍니다.

</Step>

<Step id="m2-open" title="결과 문서 열어 보기">

`ai-lab\mission2\notice-result.hwpx` 를 더블클릭해 한글에서 엽니다.

한글이 없는 컴퓨터라면 다음 중 하나로 볼 수 있습니다.

- [rhwp 웹 뷰어](https://edwardkim.github.io/rhwp/): 설치 없이 브라우저에서 열기
- 한컴오피스 뷰어(무료 설치) 또는 한컴독스(웹)

<Callout kind="warn">
웹 뷰어에 올린 파일이 어디서 처리되는지 확인되지 않았습니다. 실제 학생 정보가 든 문서는 올리지 마세요.
</Callout>

날짜·요일·마감일이 메모와 같은지 **꼭 확인** 하세요. AI가 쓴 문서는 보내기 전에 사람이 검토합니다.

</Step>

<Step id="m2-edit" title="말로 고치기">

```prompt
본문을 두 문장으로 줄이고, 당부 사항에 "비가 오면 일정이 바뀔 수 있으며 전날 문자로 안내합니다"를 추가해서 notice-result.hwpx 를 다시 만들어 줘.
```

한글에서 결과 파일을 열어 두었다면 먼저 닫으세요. 열려 있으면 새로 저장하지 못합니다.

</Step>

<Step id="m2-own" title="내 양식으로 해 보기 (시간이 남으면)">

1. 한글에서 자주 쓰는 양식을 열고, 채울 곳에 `{{칸이름}}` 을 적습니다. 예: `{{행사명}}`, `{{일시}}`
2. **다른 이름으로 저장** 에서 파일 형식을 **HWPX** 로 골라 `ai-lab\mission2` 에 저장합니다.
3. AI에게 부탁합니다.

```prompt
mission2 폴더의 (내 양식 파일 이름).hwpx 양식을 아래 내용으로 채워서 새 파일로 저장해 줘.
- 행사명: …
- 일시: …
```

</Step>

</Steps>
