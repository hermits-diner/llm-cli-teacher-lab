# 3교시 가정통신문 채우기

<p className="lead">AI에게 한글 파일 다루는 법(스킬)을 설치해 달라고 하고, 행사 메모로 한글 양식의 빈칸을 채웁니다. 35분.</p>

<PagePhoto id="mission-2" />

<Callout kind="check" title="이번 시간에 남는 것">
- 한글에서 바로 열어 인쇄할 수 있는 가정통신문 `notice-result.hwpx`
- 내 컴퓨터에 설치된 **hwpx 스킬**. 연수가 끝난 뒤에도 어느 폴더에서나 씁니다.
</Callout>

## 원리

**스킬** 은 AI에게 주는 작업 요령서 폴더입니다. hwpx 스킬에는 한글 파일을 읽고 채우는 방법과 그 일을 하는 프로그램이 들어 있습니다. 설치하면 AI가 한글 파일을 다룰 줄 알게 됩니다.

양식에는 `{{제목}}`, `{{일시}}` 처럼 **채울 자리** 가 표시되어 있습니다. AI가 메모를 읽고 자리마다 문장을 쓰면, 스킬의 도구가 그 자리에 넣습니다. 글꼴·표·줄 간격은 양식 그대로이고, 원본은 두고 **새 파일** 로 저장합니다.

<More title="이번에 설치하는 스킬">

- [jkf87/hwpx-skill](https://github.com/jkf87/hwpx-skill): GitHub에 공개된 한글 문서 스킬입니다. 양식 채우기, 공문·보고서 만들기, hwp→hwpx 변환을 합니다.
- 설명서에는 MIT 라이선스라고 적혀 있습니다(별도 LICENSE 파일은 없음). 이 사이트가 나눠 주지 않고, 선생님이 원본에서 직접 설치합니다.
- Python으로 돌아갑니다. 설치 프로그램(setup.bat)이 Python을 미리 깔아 두었습니다.
- 스킬은 선생님 권한으로 프로그램을 실행합니다. 믿을 수 있는 곳의 스킬만 설치하세요.

</More>

<More title="두 명령이 하는 일">

- `npx -y skills add …` : GitHub에서 스킬을 받아 **내 도구의 스킬 폴더** 에 복사합니다. `-g` 는 이 폴더만이 아니라 **컴퓨터 전체(전역)** 에 설치한다는 뜻이고, `-a` 뒤는 도구 이름입니다.
- `python -m pip install …` : 스킬이 쓰는 Python 부품을 설치합니다.

| 도구 | 스킬이 설치되는 곳 |
| --- | --- |
| Antigravity CLI | `사용자 폴더\.agents\skills` (설치 프로그램이 이 폴더를 읽도록 등록해 둠) |
| Codex CLI | `사용자 폴더\.agents\skills` |
| Claude Code | `사용자 폴더\.claude\skills` |

</More>

<Step id="m2-fill" title="채워 달라고 부탁하기">

<Prompt>{prompts.m2}</Prompt>

AI가 하는 일을 지켜봅니다. **1~3분** 걸립니다.

<More title="AI가 하는 일 자세히">

1. hwpx 스킬의 설명서를 읽습니다.
2. 메모를 읽고 `{{칸이름}}` 마다 들어갈 문장을 정해 파일(대응표)로 씁니다.
3. 스킬의 도구로 양식을 채워 `notice-result.hwpx` 를 만듭니다.
4. 빈칸이 남았는지, 파일 구조가 올바른지 스스로 검사하고 알려 줍니다.

</More>

</Step>

<Step id="m2-open" title="결과 확인하기">

`ai-lab\mission2\notice-result.hwpx` 를 더블클릭해 한글에서 엽니다. 날짜·요일·마감일이 메모와 같은지 **꼭 확인** 하세요.

<More title="한글이 없는 컴퓨터라면">

- [rhwp 웹 뷰어](https://edwardkim.github.io/rhwp/): 설치 없이 인터넷 창에서 열기
- 한컴오피스 뷰어(무료) 또는 한컴독스(웹)

웹 뷰어에 올린 파일이 어디서 처리되는지는 확인되지 않았습니다. 실제 학생 정보가 든 문서는 올리지 마세요.

</More>

</Step>

<Step id="m2-edit" title="말로 고치기">

```prompt
본문을 두 문장으로 줄이고, 당부 사항에 "비가 오면 일정이 바뀔 수 있으며 전날 문자로 안내합니다"를 추가해서 notice-result.hwpx 를 다시 만들어 줘.
```

한글에서 결과 파일을 열어 두었다면 먼저 닫으세요. 열려 있으면 저장하지 못합니다.

</Step>

<Step id="m2-own" title="내 양식으로 해 보기 (시간이 남으면)">

1. 자주 쓰는 한글 양식에서 채울 곳에 `{{행사명}}`, `{{일시}}` 처럼 적습니다.
2. **다른 이름으로 저장** → 파일 형식 **HWPX** → `ai-lab\mission2` 에 저장합니다.
3. 부탁합니다.

```prompt
hwpx 스킬로 mission2 폴더의 (내 양식 파일 이름).hwpx 양식을 아래 내용으로 채워서 새 파일로 저장해 줘.
- 행사명: …
- 일시: …
```

스킬은 전역으로 설치했으니, 연수 뒤에는 내 업무 폴더에서 AI를 켜고 같은 방법으로 부탁하면 됩니다.

</Step>

</Steps>
