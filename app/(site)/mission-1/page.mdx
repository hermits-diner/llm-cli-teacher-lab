# 2교시 학급 안내 웹페이지

<p className="lead">AI에게 웹페이지를 만들게 하고, 인터넷에 올려 휴대폰으로 열어 봅니다. 20분.</p>

<Callout kind="check" title="이번 시간에 남는 것">
누구나 열 수 있는 내 웹페이지 주소 `https://(내가 정한 이름).netlify.app`
</Callout>

<Steps>

<Step id="m1-make" title="만들어 달라고 부탁하기">

1교시에 켜 둔 AI 창에 붙여넣습니다. 창을 닫았다면 [다시 켜세요](/start#start-run).

<Prompt>{prompts.m1}</Prompt>

결재 요청이 오면 읽고 허락합니다. **1~5분** 걸립니다.

</Step>

<Step id="m1-open" title="열어 보기">

`ai-lab` 폴더의 `mission1\site\index.html` 을 더블클릭합니다. AI에게 "만든 페이지 열어 줘" 라고 해도 됩니다.

인터넷 창의 폭을 좁히면 휴대폰에서 어떻게 보일지 알 수 있습니다.

</Step>

<Step id="m1-edit" title="말로 고치기">

<Prompt>{prompts.m1edit}</Prompt>

<kbd>F5</kbd> 로 새로고침하면 바뀐 모습이 보입니다. "3교시를 체육으로 바꿔 줘" 처럼 **구체적일수록** 정확합니다.

</Step>

<Step id="m1-deploy" title="인터넷에 올리기 (Netlify)">

1. [app.netlify.com/drop](https://app.netlify.com/drop) 을 엽니다. **로그인한 상태** 여야 합니다.
2. `ai-lab\mission1` 안의 **`site` 폴더** 를 인터넷 창의 상자에 끌어다 놓습니다.
3. 주소가 생기면 **Make public** 버튼이 보일 때 눌러 공개합니다.

<Callout kind="warn" title="반드시 로그인한 뒤 올리기">
로그인하지 않고 올리면 비밀번호가 걸리고 곧 지워집니다.
</Callout>

<More title="주소 바꾸기, 올리는 횟수 제한">

- 사이트 설정에서 이름을 바꾸면 `https://우리반-안내.netlify.app` 처럼 기억하기 쉬운 주소가 됩니다(영문·숫자·하이픈 권장).
- 무료 요금제는 매달 사용 포인트 300점, 한 번 올릴 때 15점입니다. 한 달에 20번쯤이니, 내 컴퓨터에서 충분히 고친 뒤 올리세요.

</More>

</Step>

<Step id="m1-share" title="휴대폰으로 열고 갤러리에 올리기">

휴대폰에서 내 주소를 열어 봅니다. 잘 열리면 [결과물 갤러리](/gallery) 에 올리고 다른 선생님들의 페이지도 구경하세요.

</Step>

</Steps>

<More title="막혔을 때">

- 만든 페이지가 없거나 이상하면 완성 예시 폴더 `ai-lab\samples\mission1` 을 대신 올려 보세요. 올리는 경험은 똑같습니다.
- 그 밖의 문제는 [막혔어요](/help) 를 보세요.

</More>

<More title="집에서 해 보기: AI에게 올리기까지 맡기기">

처음 한 번은 직접 로그인합니다. `ai-lab` 폴더 위쪽 주소창에 `cmd` 를 입력해 검은 창을 열고:

```cmd
@cwd C:\Users\선생님\Desktop\ai-lab
tools\node\npx -y netlify-cli login
```

인터넷 창에서 허락한 뒤, AI 창에서 부탁합니다.

```prompt
mission1/site 폴더를 Netlify에 새 사이트로 배포해 줘. npx -y netlify-cli deploy --dir mission1/site --no-build --prod 명령을 쓰고, 끝나면 사이트 주소를 알려 줘.
```

</More>
