# 만들 수 있는 파일과 부탁 예시

<p className="lead">LLM CLI가 만들 수 있는 파일 형식을 수업과 업무에 쓰는 예시로 모았습니다. 부탁 문장을 복사해 학년·과목·내용만 바꿔 쓰세요.</p>

<LevelPicker />

<Callout title="부탁할 때 세 가지만 지키세요">
- **파일 이름을 적습니다.** 예: "quiz.html 로 저장해 줘". 이름을 적지 않으면 AI가 실습 파일을 고칠 수 있습니다.
- **학생 개인정보는 넣지 않습니다.** 이름·연락처·성적이 필요한 자리에는 번호나 가상의 데이터를 씁니다.
- **결과는 직접 열어 확인합니다.** 날짜·요일·숫자·사실관계는 특히 다시 봅니다.
</Callout>

## 한눈에 보기

AI는 **글자로 이루어진 파일** 은 거의 무엇이든 바로 만듭니다. 한글·Word·Excel처럼 안쪽 구조가 복잡한 파일은 준비된 도구를 쓰거나, 다른 형식으로 만들어 대신합니다.

| 파일 형식 | 여는 프로그램 | 수업에서 | 업무에서 | 실습 폴더에서 |
| --- | --- | --- | --- | --- |
| 웹페이지 `.html` | 브라우저 | 퀴즈, 타이머, 발표 순서 뽑기 | 학급 안내, 행사 안내 페이지 | 바로 됨 |
| 시뮬레이션 `.html` | 브라우저 | 입자 운동, 빛의 굴절, 포물선 운동, 함수 그래프 | | 바로 됨 |
| p5.js 스케치 `.html` | 브라우저 (인터넷 연결) | 코딩 단계별 예제, 정렬 알고리즘, 대칭 무늬 그리기 | 행사 대기 화면, 포스터 배경 그림 | 인터넷이 되면 바로 됨 |
| 글 문서 `.txt` `.md` | 메모장 | 수준별 읽기 자료, 발문 목록 | 회의록, 공문 초안 | 바로 됨 |
| 표 `.csv` | Excel, 한셀 | 단어장, 모둠 역할표 | 학사일정, 물품 목록 | 바로 됨 |
| 달력 `.ics` | 구글 캘린더, Outlook | 수행평가 일정 | 학사일정 가져오기 | 바로 됨 |
| 그림 `.svg` | 브라우저 | 개념도, 구조 그림 | 교실 배치도 | 바로 됨 |
| 자동 실행 `.bat` | 더블클릭 | 수업 자료 폴더 열기 | 날짜별 폴더 만들기 | 바로 됨 |
| 한글 `.hwpx` | 한글 | 활동지 | 가정통신문, 회의록 | 준비된 도구로 **양식 채우기** |
| 발표 자료 (`.pptx` 대신) | 브라우저 | 수업 도입 슬라이드 | 학부모 총회 자료 | 웹 슬라이드 `.html` 로 대신 |
| 인쇄물·PDF (`.pdf` 대신) | 브라우저 → PDF로 저장 | 학습지, 형성평가지 | 회의 안건지 | 웹페이지로 만든 뒤 인쇄 |
| Word·Excel `.docx` `.xlsx` | Word, Excel | | | 아래 [대신하는 방법](#office) 참고 |

## 시뮬레이션 (.html)

과학·수학 시간에 쓰는 **움직이는 자료** 입니다. 슬라이더로 값을 바꾸면 그림과 그래프가 바로 바뀝니다. 웹페이지 한 파일이라 설치 없이 교실 TV의 브라우저에서 바로 열리고, [Vercel](/mission-1) 에 올리면 학생 휴대폰에서도 열어 볼 수 있습니다. 부탁 끝에 **"외부 라이브러리 없이 한 파일로"** 를 붙이면 인터넷이 끊겨도 돌아갑니다.

</Callout>

## p5.js 스케치 (.html)

p5.js는 그림과 움직임을 짧은 코드로 그리는 자바스크립트 도구(라이브러리)입니다. 코드가 짧고 읽기 쉬워 **학생에게 코드를 보여 주며 가르치기 좋고**, 움직이는 무늬·게임·행사 화면처럼 그림이 중심인 자료에 잘 맞습니다. 위의 시뮬레이션과 달리 p5.js를 인터넷에서 불러오므로 **인터넷이 연결된 컴퓨터에서 열립니다.**

부탁에 **"p5.js 1.x 버전"** 을 적어 두었습니다. 최신 2.x는 문법이 일부 바뀌어서, AI가 두 버전을 섞어 쓰면 빈 화면만 나올 수 있습니다.

<ForLevel level="middle">

**수업 · 중학교** 정보 '반복 구조' 단계별 예제

```prompt
repeat.html 로 중학교 정보 '반복 구조' 수업용 p5.js 예제를 만들어 줘. 1단계(원 하나) → 2단계(for 문으로 원 한 줄) → 3단계(이중 for 문으로 격자) → 4단계(반복할 때마다 크기·색 바꾸기)를 버튼으로 넘기며 보여 주고, 그림 옆에 그 단계의 코드와 한 줄 설명을 함께 보여 줘. 학생이 p5.js 웹 에디터에 붙여 고쳐 볼 수 있게 단계마다 코드 복사 버튼도 넣어 줘. p5.js 1.x 버전을 인터넷 주소(CDN)로 불러와 한 파일로.
```

<h2 id="office">Word·Excel 정식 파일 (.docx, .xlsx)</h2>

이런 파일은 안쪽이 여러 파일을 묶은 압축 구조라, 만들려면 전용 프로그램이 필요합니다. 실습 폴더에는 그 프로그램이 없고, 연수 중에는 **프로그램을 새로 설치하지 않습니다.** AI가 무언가를 설치하려고 하면 <kbd>Esc</kbd> 로 멈추고 "설치하지 말고 다른 방법으로 해 줘" 라고 말하세요.

대신 이렇게 하면 됩니다.

| 원하는 파일 | 대신 만드는 것 | 이어서 할 일 |
| --- | --- | --- |
| Excel 표 (`.xlsx`) | `.csv` (UTF-8 BOM) | Excel에서 열고 **다른 이름으로 저장 → Excel 통합 문서** |
| Word 문서 (`.docx`) | `.html` | Word에서 열고 **다른 이름으로 저장 → Word 문서** |
| 한글 문서 (`.hwpx`) | 내 양식 + `{{칸이름}}` | 위의 [한글 문서](#hwpx) 방법 |

- 들어갈 내용: (예: 문제 5개, 일정 표, 인사말)
