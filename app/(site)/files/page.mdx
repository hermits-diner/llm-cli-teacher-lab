# 만들 수 있는 파일과 부탁 예시

<p className="lead">LLM CLI가 만들 수 있는 파일 형식을 수업과 업무에 쓰는 예시로 모았습니다. 부탁 문장을 복사해 학년·과목·내용만 바꿔 쓰세요.</p>

<Callout title="부탁할 때 세 가지만 지키세요">
- **파일 이름과 위치를 적습니다.** 예: "만들기 폴더에 quiz.html 로 저장해 줘". 이름을 적지 않으면 AI가 실습 파일을 고칠 수 있습니다.
- **학생 개인정보는 넣지 않습니다.** 이름·연락처·성적이 필요한 자리에는 번호나 가상의 데이터를 씁니다.
- **결과는 직접 열어 확인합니다.** 날짜·요일·숫자·사실관계는 특히 다시 봅니다.
</Callout>

## 한눈에 보기

AI는 **글자로 이루어진 파일** 은 거의 무엇이든 바로 만듭니다. 한글·Word·Excel처럼 안쪽 구조가 복잡한 파일은 준비된 도구를 쓰거나, 다른 형식으로 만들어 대신합니다.

| 파일 형식 | 여는 프로그램 | 수업에서 | 업무에서 | 실습 폴더에서 |
| --- | --- | --- | --- | --- |
| 웹페이지 `.html` | 브라우저 | 퀴즈, 타이머, 발표 순서 뽑기 | 학급 안내, 행사 안내 페이지 | 바로 됨 |
| 글 문서 `.txt` `.md` | 메모장 | 수준별 읽기 자료, 발문 목록 | 회의록, 공문 초안 | 바로 됨 |
| 표 `.csv` | Excel, 한셀 | 단어장, 모둠 역할표 | 학사일정, 물품 목록 | 바로 됨 |
| 달력 `.ics` | 구글 캘린더, Outlook | 수행평가 일정 | 학사일정 가져오기 | 바로 됨 |
| 그림 `.svg` | 브라우저 | 개념도, 구조 그림 | 교실 배치도 | 바로 됨 |
| 자동 실행 `.bat` | 더블클릭 | 수업 자료 폴더 열기 | 날짜별 폴더 만들기 | 바로 됨 |
| 한글 `.hwpx` | 한글 | 활동지 | 가정통신문, 회의록 | 준비된 도구로 **양식 채우기** |
| 발표 자료 (`.pptx` 대신) | 브라우저 | 수업 도입 슬라이드 | 학부모 총회 자료 | 웹 슬라이드 `.html` 로 대신 |
| 인쇄물·PDF (`.pdf` 대신) | 브라우저 → PDF로 저장 | 학습지, 형성평가지 | 회의 안건지 | 웹페이지로 만든 뒤 인쇄 |
| Word·Excel `.docx` `.xlsx` | Word, Excel | | | 아래 [대신하는 방법](#office) 참고 |

## 웹페이지 (.html)

글, 표, 버튼, 계산까지 한 파일에 담을 수 있어 가장 쓸모가 많습니다. 더블클릭하면 브라우저에서 열리고, [Netlify](/mission-1) 에 올리면 주소로 공유할 수 있습니다.

**수업** 단원 복습 퀴즈

```prompt
만들기 폴더에 quiz.html 로 중학교 1학년 과학 '물질의 상태 변화' 복습 퀴즈를 만들어 줘. 객관식 5문제, 문제마다 정답 확인 버튼이 있고 맞으면 초록색, 틀리면 빨간색으로 해설을 보여 줘. 휴대폰에서도 보기 좋게.
```

**수업** 교실 도구

```prompt
만들기 폴더에 picker.html 로 발표 순서 뽑기 도구를 만들어 줘. 1번부터 28번까지 번호 중에서 버튼을 누르면 하나씩 뽑고, 이미 뽑힌 번호는 다시 나오지 않게, 숫자는 교실 뒤에서도 보이게 크게 해 줘.
```

**업무** 행사 안내 페이지

```prompt
만들기 폴더에 event.html 로 학부모 공개수업 안내 페이지를 만들어 줘. 날짜, 시간표, 오시는 길, 주차 안내, 문의처 칸을 넣고 내용은 가상으로 채워 줘. 학부모님이 휴대폰으로 보기 좋게.
```

## 글 문서 (.txt, .md)

메모를 정리하거나 문장을 다듬을 때 씁니다. 결과를 한글 문서나 메일에 붙여넣어 쓰면 됩니다.

**수업** 수준별 읽기 자료

```prompt
만들기 폴더의 지문.txt 를 읽고 같은 내용을 세 수준으로 다시 써서 지문-수준별.txt 로 저장해 줘. 기본(초등 고학년 수준의 쉬운 낱말), 보통(원문과 비슷하게), 심화(배경지식 한 문단 추가). 수준마다 이해 확인 질문 2개씩.
```

**업무** 회의록 정리

```prompt
만들기 폴더의 회의메모.txt 를 읽고 회의록으로 정리해서 회의록.txt 로 저장해 줘. 일시, 참석, 안건, 결정 사항, 할 일(담당·기한) 순서로 쓰고, 메모에 없는 내용은 지어내지 말고 '확인 필요'라고 적어 줘.
```

## 표 (.csv)

Excel이나 한셀에서 열리는 표 파일입니다. 한글이 깨지지 않도록 부탁 끝에 **UTF-8 BOM** 을 꼭 넣으세요.

**수업** 단어장

```prompt
만들기 폴더에 단어장.csv 를 만들어 줘. 중학교 2학년 영어 3단원 수준의 낱말 20개를 낱말, 품사, 뜻, 예문, 예문 해석 열로 정리해 줘. 엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 저장해 줘.
```

**업무** 학사일정

```prompt
만들기 폴더에 학사일정.csv 를 만들어 줘. 2학기 9월부터 12월까지 날짜, 요일, 행사, 비고 열로 정리하고 행사 내용은 가상으로 채워 줘. 요일이 날짜와 맞는지 꼭 확인하고, 엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 저장해 줘.
```

## 달력 일정 (.ics)

구글 캘린더나 Outlook에서 **가져오기** 하면 일정이 한꺼번에 들어갑니다.

**업무** 학사일정을 내 캘린더로

```prompt
만들기 폴더의 학사일정.csv 를 읽고 구글 캘린더에서 가져오기 할 수 있는 학사일정.ics 파일로 만들어 줘. 하루 종일 일정으로, 시간대는 Asia/Seoul로 해 줘.
```

**수업** 수행평가 일정

```prompt
만들기 폴더에 수행평가.ics 를 만들어 줘. 10월 14일 국어 발표, 10월 21일 수학 탐구 보고서 제출, 10월 28일 과학 실험 평가를 하루 종일 일정으로 넣고, 각 일정 이틀 전에 알림이 오게 해 줘. 시간대는 Asia/Seoul.
```

## 그림 (.svg)

도형과 글자로 된 그림을 만듭니다. 브라우저로 열어 보고, 웹페이지나 학습지에 넣어 씁니다. 사진처럼 그리는 그림은 만들지 못합니다.

**수업** 개념 그림

```prompt
만들기 폴더에 식물세포.svg 를 만들어 줘. 식물 세포를 단순한 도형으로 그리고 세포벽, 세포막, 핵, 엽록체, 액포에 선을 그어 이름을 붙여 줘. 글자는 크게, 색은 인쇄해도 구분되게.
```

**업무** 교실 배치도

```prompt
만들기 폴더에 교실배치도.svg 를 만들어 줘. 앞에 칠판과 교탁, 가운데 책상 6줄 5열, 뒤에 사물함이 있는 교실을 위에서 내려다본 모습으로, 책상에는 1번부터 30번까지 번호를 적어 줘.
```

## 자동 실행 (.bat)

더블클릭하면 정해진 일을 하는 파일입니다. 처음에는 꼭 **실습 폴더 안에서만** 동작하게 부탁하세요.

**업무** 날짜별 작업 폴더

```prompt
만들기 폴더에 오늘폴더.bat 를 만들어 줘. 더블클릭하면 같은 폴더 안에 '2026-11-12'처럼 오늘 날짜 이름의 폴더를 만들고 그 폴더를 열어 주게 해 줘. 이미 있으면 새로 만들지 말고 열기만 해 줘.
```

**수업** 수업 자료 한 번에 열기

```prompt
만들기 폴더에 수업시작.bat 를 만들어 줘. 더블클릭하면 같은 폴더의 quiz.html 과 picker.html 을 브라우저로 열고, 수업자료 폴더를 탐색기로 열어 주게 해 줘. 파일이 없으면 무엇이 없는지 알려 줘.
```

<h2 id="hwpx">한글 문서 (.hwpx)</h2>

실습 폴더에는 **한글 양식의 `{{칸이름}}` 자리를 채우는 도구** 가 준비되어 있습니다. 빈 문서를 처음부터 꾸미기보다, 내가 쓰는 양식에 칸 이름을 적어 두고 채우게 하는 방식이 정확합니다. 자세한 방법은 [3교시](/mission-2) 에 있습니다.

**수업** 수업 활동지

```prompt
mission2 폴더의 worksheet-form.hwpx 양식을 worksheet-memo.txt 내용으로 채워서 worksheet-result.hwpx 로 저장해 줘. 원본 양식은 그대로 두고, 채운 뒤 빈칸이 남았는지 확인해 줘.
```

**업무** 내 양식으로 회의록

```prompt
mission2 폴더의 회의록-양식.hwpx 를 만들기 폴더의 회의메모.txt 내용으로 채워서 회의록-결과.hwpx 로 저장해 줘. 원본 양식은 그대로 두고, 메모에 없는 내용은 지어내지 마.
```

내 양식은 한글에서 **다른 이름으로 저장 → 파일 형식 HWPX** 로 저장해야 합니다. 예전 형식(`.hwp`)은 다루지 못합니다.

## 발표 자료 (.pptx 대신 웹 슬라이드)

PowerPoint 파일 대신, 화살표 키로 넘기는 웹 슬라이드를 만듭니다. 교실 TV에 브라우저로 띄우면 됩니다.

**수업** 수업 도입 슬라이드

```prompt
만들기 폴더에 도입.html 로 초등 5학년 사회 '조선의 건국' 수업 도입 슬라이드를 만들어 줘. 슬라이드 4장(생각 열기 질문, 오늘의 학습 목표, 핵심 낱말 3개, 활동 안내), 키보드 화살표로 넘기고 글자는 크게.
```

**업무** 학부모 총회 자료

```prompt
만들기 폴더에 총회.html 로 학부모 총회 발표 자료를 만들어 줘. 슬라이드 6장(인사, 학급 목표, 1년 일정, 생활 규칙, 상담 안내, 마무리), 키보드 화살표로 넘기고, 글자는 크게, 내용은 가상으로 채워 줘.
```

## 인쇄물·PDF (.pdf 대신 웹페이지)

A4에 맞춘 웹페이지를 만든 뒤, 브라우저에서 <kbd>Ctrl</kbd>+<kbd>P</kbd> → **PDF로 저장** 을 고르면 PDF가 됩니다.

**수업** 학습지

```prompt
만들기 폴더에 학습지.html 로 초등 4학년 '분수의 덧셈' 학습지를 만들어 줘. A4 한 장에 인쇄되게, 위에 이름 쓰는 칸, 문제 10개, 맨 아래 정답은 접어서 가릴 수 있게 점선으로 구분해 줘.
```

**업무** 회의 안건지

```prompt
만들기 폴더의 회의록.txt 를 바탕으로 다음 회의 안건지를 안건지.html 로 만들어 줘. A4 한 장, 맨 위에 회의 이름·일시·장소, 그 아래 안건 표(번호, 안건, 제안자, 비고), 맨 아래 메모 칸. 인쇄했을 때 표 테두리가 보이게.
```

<h2 id="office">Word·Excel 정식 파일 (.docx, .xlsx)</h2>

이런 파일은 안쪽이 여러 파일을 묶은 압축 구조라, 만들려면 전용 프로그램이 필요합니다. 실습 폴더에는 그 프로그램이 없고, 연수 중에는 **프로그램을 새로 설치하지 않습니다.** AI가 무언가를 설치하려고 하면 <kbd>Esc</kbd> 로 멈추고 "설치하지 말고 다른 방법으로 해 줘" 라고 말하세요.

대신 이렇게 하면 됩니다.

| 원하는 파일 | 대신 만드는 것 | 이어서 할 일 |
| --- | --- | --- |
| Excel 표 (`.xlsx`) | `.csv` (UTF-8 BOM) | Excel에서 열고 **다른 이름으로 저장 → Excel 통합 문서** |
| Word 문서 (`.docx`) | `.html` | Word에서 열고 **다른 이름으로 저장 → Word 문서** |
| 한글 문서 (`.hwpx`) | 내 양식 + `{{칸이름}}` | 위의 [한글 문서](#hwpx) 방법 |

## 좋은 부탁을 쓰는 틀

아래 빈칸을 채우면 어떤 파일이든 부탁할 수 있습니다.

```prompt
(어느 폴더)에 (파일 이름.확장자) 로 (무엇)을 만들어 줘.
- 누가 쓰나: (예: 중학교 1학년 학생, 학부모, 동료 교사)
- 들어갈 내용: (예: 문제 5개, 일정 표, 인사말)
- 모양: (예: 휴대폰에서 보기 좋게, A4 한 장, 글자 크게)
- 지킬 것: (예: 내용은 가상으로, 없는 사실은 지어내지 않기)
다 만들면 무엇을 만들었는지 알려 주고, 확인하는 방법도 알려 줘.
```
