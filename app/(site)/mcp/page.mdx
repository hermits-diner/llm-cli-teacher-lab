# 부록: MCP로 바깥 서비스 연결하기

<p className="lead">MCP를 연결하면 AI가 내 컴퓨터 밖의 서비스(문서, 드라이브, 디자인 도구 등)를 직접 찾아보고 고칠 수 있습니다. 연수 실습에는 넣지 않은 참고 자료입니다.</p>

<Callout kind="warn" title="자동 승인 실행 파일에서는 연결하지 않기">
연수용 `start-…cmd` 는 AI가 묻지 않고 일하는 설정입니다. 이 상태로 서비스를 연결하면 AI가 묻지 않고 메일을 보내거나 문서를 고칠 수 있습니다. 내 업무 폴더에서 검은 창에 `agy`·`codex`·`claude` 만 입력해 **허락을 묻는 방식** 으로 켠 뒤 쓰세요.
</Callout>

## MCP란

**MCP**(Model Context Protocol)는 AI와 바깥 서비스를 잇는 **표준 연결선** 입니다. 한 번 연결하면 AI가 그 서비스의 기능을 도구처럼 꺼내 씁니다.

| 연결 전 | 연결 뒤 |
| --- | --- |
| 서비스에서 내용을 복사해 AI에게 붙여넣기 | "드라이브에서 지난 회의록 찾아 요약해 줘" 한 줄 |
| AI가 쓴 글을 서비스에 다시 옮기기 | AI가 서비스에 바로 만들고 고침 |

서비스마다 연결 주소가 따로 있습니다. 서비스의 도움말에서 "MCP" 를 찾으면 주소와 연결 방법이 나옵니다.

## 연결하기 전에 확인할 것

- **출처**: 서비스 회사가 직접 낸 공식 주소만 연결합니다.
- **권한**: 읽기만 하는지, 만들고 고치고 지우기까지 하는지 확인합니다. 처음엔 읽기 전용부터 써 봅니다.
- **계정**: 로그인이 필요한 서비스는 인터넷 창이 열립니다. 개인 계정과 학교 계정 중 어느 쪽으로 로그인되어 있는지 봅니다.
- **학생 정보**: 학생 이름·성적이 들어 있는 서비스는 연결하지 않습니다.

## 따라 하기: 로그인 없는 공식 문서 검색

Microsoft가 공개한 **Microsoft Learn** 문서 검색을 연결해 봅니다. 엑셀·워드·윈도우 사용법을 공식 문서에서 찾아 줍니다. 로그인이 없고 **읽기만** 하므로 연습에 알맞습니다.

<ForTool tool="agy">

검은 창(cmd)에서 실행합니다.

```cmd
agy mcp add mslearn https://learn.microsoft.com/api/mcp
agy mcp list
```

목록에 `mslearn` 이 `enabled` 로 보이면 연결된 것입니다.

</ForTool>
<ForTool tool="codex">

검은 창(cmd)에서 실행합니다.

```cmd
codex mcp add mslearn --url https://learn.microsoft.com/api/mcp
codex mcp list
```

목록에 `mslearn` 이 `enabled` 로 보이면 연결된 것입니다.

</ForTool>
<ForTool tool="claude">

작업할 폴더에서 검은 창(cmd)을 열고 실행합니다. 이 폴더에서만 연결됩니다.

```cmd
claude mcp add --transport http mslearn https://learn.microsoft.com/api/mcp
claude mcp list
```

목록에 `mslearn` 옆에 `✔ Connected` 가 보이면 연결된 것입니다. 모든 폴더에서 쓰려면 `add` 뒤에 `--scope user` 를 붙입니다.

</ForTool>

도구를 켜고 부탁합니다. 허락을 묻는 방식으로 켰다면, AI가 이 연결을 처음 쓸 때 허락을 구합니다.

```prompt
Microsoft 공식 문서에서 엑셀 XLOOKUP 함수 사용법을 찾아, 학급 명렬표에서 번호로 이름을 찾는 예시와 함께 3줄로 정리해 줘. 찾은 문서 주소도 알려 줘.
```

AI가 찾은 문서 주소를 함께 알려 줍니다. 답을 그대로 믿지 말고 주소를 열어 확인합니다.

## 로그인이 필요한 서비스

구글 드라이브, 노션, 캔바처럼 내 계정의 자료를 다루는 서비스는 연결할 때 **인터넷 창에서 로그인하고 허락** 합니다.

- 연결하자마자 "내 ○○에서 최근 자료 3개 제목을 보여 줘" 처럼 물어 **어느 계정이 연결됐는지** 확인합니다.
- 학교(교육용) 계정은 관리자가 연결을 막아 두었을 수 있습니다.
- 실제 예시는 [부록: Canva 연결해 슬라이드 만들기](/canva) 에 있습니다.

## 연결 확인하고 끊기

| 하고 싶은 일 | Antigravity CLI | Codex CLI | Claude Code |
| --- | --- | --- | --- |
| 연결 목록 | `agy mcp list` | `codex mcp list` | `claude mcp list` |
| 연결 끊기 | `agy mcp remove 이름` | `codex mcp remove 이름` | `claude mcp remove 이름` |
| 잠시 끄기 | `agy mcp disable 이름` | (끊었다가 다시 연결) | (끊었다가 다시 연결) |
| 로그인 다시 하기 | (끊었다가 다시 연결) | `codex mcp login 이름` | 대화창에서 `/mcp` |

<Callout kind="warn" title="연결 목록은 발표 화면에 띄우지 않기">
서비스에 따라 연결 목록에 **비밀 키가 그대로** 보입니다. 화면 공유나 프로젝터에 띄운 상태에서 목록 명령을 실행하지 마세요. 키가 노출되면 그 서비스에서 키를 새로 발급받습니다.
</Callout>

다 썼거나 잘 모르는 연결은 끊어 둡니다. 연결이 많을수록 AI가 엉뚱한 도구를 고를 수 있습니다.
