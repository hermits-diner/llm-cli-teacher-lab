# 1교시 첫 만남

<p className="lead">AI에게 말을 걸고, AI의 결재 요청을 읽는 법을 익힙니다. 10분.</p>

## 챗봇과 무엇이 다른가요

| | 웹 챗봇 | LLM CLI (오늘 쓰는 도구) |
| --- | --- | --- |
| 일하는 곳 | 인터넷 창의 대화창 | 내 컴퓨터의 폴더 |
| 결과 | 글로 답함. 파일은 내가 만듦 | 파일을 **직접** 만들고 고침 |
| 선생님이 할 일 | 복사·붙여넣기 | 결재 요청을 **읽고 허락하기** |

AI가 직접 파일을 만들기 때문에 중요한 일 전에는 **결재를 올립니다**. 이것을 읽는 법이 오늘의 핵심입니다.

## 시작하기

<Steps>

<Step id="start-run" title="도구 켜기">

바탕화면 `ai-lab` 폴더에서 더블클릭합니다.

<ForTool tool="agy">`start-agy.cmd`</ForTool>
<ForTool tool="codex">`start-codex.cmd`</ForTool>
<ForTool tool="claude">`start-claude.cmd`</ForTool>

<More title="검은 창에서 직접 켜기">

`ai-lab` 폴더 위쪽 주소창에 `cmd` 를 입력하고 <kbd>Enter</kbd> 를 누르면 이 폴더에서 검은 창이 열립니다. 거기에 입력합니다.

<ForTool tool="agy">

```cmd
start-agy
```

</ForTool>
<ForTool tool="codex">

```cmd
start-codex
```

</ForTool>
<ForTool tool="claude">

```cmd
start-claude
```

</ForTool>

</More>

</Step>

<Step id="start-hello" title="말 걸기">

이 문장을 **복사해 붙여넣는** 것이 가장 확실합니다. 검은 창에서 한글을 직접 치면 마지막 글자가 밀릴 때가 있습니다.

<Prompt>{prompts.hello}</Prompt>

<ForTool tool="claude">

직접 칠 때는 끝에 <kbd>Space</kbd> 를 한 번 누르고 <kbd>Enter</kbd>.

</ForTool>

</Step>

<Step id="start-approve" title="결재 요청 읽기">

AI가 파일을 만들거나 프로그램을 실행하기 전에 이렇게 묻습니다.

```screen
 Allow this command?
   node tools/hwpx-fill.mjs --list mission2/notice-form.hwpx

 > 1. Yes
   2. Yes, and don't ask again for this command
   3. No, and tell the AI what to do differently
```

- **무엇을 하려는지** 한 줄만 읽습니다. 이 예는 "양식의 빈칸 목록 보기" 입니다.
- 이해되면 **Yes**(화살표로 고르고 <kbd>Enter</kbd>).
- 모르겠으면 **No** → "이게 무슨 뜻이야?"
- `ai-lab` 폴더 밖의 파일을 지우거나 바꾸려 하면 **No**.

</Step>

</Steps>

<More title="도구 안에서 쓰는 명령">

입력창에 `/` 로 시작하는 글을 치면 명령입니다. 오늘 쓰는 것만 골랐습니다. 전체는 [도구별 명령어](/commands) 에 있습니다.

<ForTool tool="agy">

| 하고 싶은 일 | 입력 |
| --- | --- |
| 도움말 | `/help` |
| 새 대화 | `/clear` |
| 남은 사용량 | `/usage` |
| 끝내기 | `/exit` |
| 일하는 방식 바꾸기 | <kbd>Shift</kbd>+<kbd>Tab</kbd> |

</ForTool>

<ForTool tool="codex">

| 하고 싶은 일 | 입력 |
| --- | --- |
| 새 대화 | `/new` |
| 상태·사용량 | `/status` |
| 허락 범위 바꾸기 | `/permissions` |
| 끝내기 | `/quit` |

</ForTool>

<ForTool tool="claude">

| 하고 싶은 일 | 입력 |
| --- | --- |

| 새 대화 | `/clear` |
| 남은 사용량 | `/usage` |
| 끝내기 | `/exit` |
| 일하는 방식 바꾸기 | <kbd>Shift</kbd>+<kbd>Tab</kbd> |

</ForTool>

AI가 일하는 중에 멈추려면 <kbd>Esc</kbd>.

</More>

## 지켜 주세요

- **학생 개인정보는 넣지 않습니다.** 예시가 필요하면 가상 데이터를 씁니다.
- **결과는 사람이 확인한 뒤** 씁니다. 날짜·요일·숫자는 특히.
- **결재 요청은 읽고** 답합니다. 습관처럼 Yes를 누르지 않습니다.
