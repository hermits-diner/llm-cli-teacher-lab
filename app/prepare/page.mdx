# 연수 전 준비

<p className="lead">연수 날 바로 실습할 수 있도록 미리 해 두는 일입니다. 30분 정도 걸리고, 대부분은 기다리는 시간입니다.</p>

<Callout kind="warn" title="연수 당일에 설치하지 마세요">
여러 명이 같은 와이파이로 동시에 설치하면 오래 걸리고 실패하기 쉽습니다. 재부팅하면 설치 내용이 지워지는 학교 공용 PC(복원 프로그램)는 쓰지 말고, **개인 노트북**을 가져오세요.
</Callout>

## 위에서 내 도구를 고르세요

페이지 맨 위 **내 도구**에서 하나를 고르면, 이 사이트의 모든 명령과 설명이 그 도구에 맞게 바뀝니다. 이미 쓰고 있는 구독을 기준으로 고르면 됩니다.

| 도구 | 필요한 계정 | 비용 |
| --- | --- | --- |
| Antigravity CLI | 개인 Gmail | 무료로 시작 (주간 사용량 한도) |
| Codex CLI | ChatGPT | ChatGPT 유료 요금제(Plus 이상) |
| Claude Code | Claude | Claude Pro 이상 (무료 요금제 불가) |

<ForTool tool="agy">
<Callout kind="warn" title="Antigravity CLI는 개인 Gmail로">
학교에서 받은 Google Workspace 계정은 로그인이 막힐 수 있습니다. `@gmail.com` 개인 계정을 준비하세요. 만 18세 이상만 쓸 수 있으므로 학생 수업용으로는 쓸 수 없습니다.
</Callout>
</ForTool>

<ForTool tool="codex">
<Callout kind="warn" title="Codex CLI는 ChatGPT 유료 요금제로">
ChatGPT 무료 요금제에서 Codex CLI를 쓸 수 있는지는 확인되지 않았습니다. Plus 이상 요금제로 로그인하세요.
</Callout>
</ForTool>

<ForTool tool="claude">
<Callout kind="warn" title="Claude Code는 Pro 이상 구독으로">
claude.ai 무료 요금제로는 Claude Code를 쓸 수 없습니다. Pro 이상 구독이 필요합니다.
</Callout>
</ForTool>

## 준비 순서

<Steps>

<Step id="prep-netlify" title="Netlify에 가입하고 공개 설정 바꾸기">

2교시에 만든 웹페이지를 인터넷에 올릴 때 씁니다.

1. [app.netlify.com](https://app.netlify.com/signup) 에서 이메일이나 GitHub 계정으로 가입합니다.
2. 2026년 7월 28일 이후에 가입한 계정은 새 사이트가 **비공개**로 시작합니다. 팀 설정(Team settings)의 방문자 접근(Visitor access)에서 기본 공개 범위(Default project visibility)를 **Public** 으로 바꿔 두세요.

메뉴를 못 찾아도 괜찮습니다. 연수 때 사이트마다 **Make public** 버튼을 누르면 됩니다.

</Step>

<Step id="prep-cmd" title="명령 프롬프트(cmd) 열기">

1. 키보드의 <kbd>Windows</kbd> 키를 누르고 `cmd` 를 입력합니다.
2. **명령 프롬프트** 를 클릭합니다.
3. 검은 창에 `C:\Users\(내 이름)>` 처럼 보이면 맞게 연 것입니다.

<Callout kind="warn">
`PS C:\Users\...>` 처럼 앞에 **PS** 가 붙어 있으면 PowerShell입니다. 아래 명령이 동작하지 않으니 창을 닫고 다시 `cmd` 로 여세요.
</Callout>

</Step>

<Step id="prep-install" title="한 줄로 설치하기">

아래 명령을 복사해서 검은 창에 붙여넣고 <kbd>Enter</kbd> 를 누릅니다. 붙여넣기는 <kbd>Ctrl</kbd>+<kbd>V</kbd> 또는 마우스 오른쪽 클릭입니다.

<Cmd>{`curl -fsSL ${SITE_URL}/setup.bat -o "%TEMP%\\ai-lab-setup.bat" && "%TEMP%\\ai-lab-setup.bat"`}</Cmd>

설치 프로그램이 영어 메뉴를 보여 줍니다. 내 도구의 번호를 누르세요.

| 누를 키 | 도구 |
| --- | --- |
| <kbd>1</kbd> | Claude Code |
| <kbd>2</kbd> | Codex CLI |
| <kbd>3</kbd> | Antigravity CLI |
| <kbd>4</kbd> | 설치 없이 이 PC 점검만 |

그다음은 기다리면 됩니다. 실습 폴더(바탕화면의 `ai-lab`), Node.js, AI 도구를 차례로 설치하고 마지막에 결과를 보여 줍니다.

```screen
 ======================== RESULT ========================
   PC check          : OK
   Internet          : OK
   Practice folder   : OK
   Node.js           : OK v24.22.0
   Antigravity CLI   : OK 1.4.3
 ========================================================
   All done.
```

모두 `OK` 이면 성공입니다. 바탕화면에 생긴 `ai-lab` 폴더가 자동으로 열립니다. `FAIL` 이 있으면 화면 아래의 오류 코드(예: `E05`)로 [도움말](/help) 에서 해결 방법을 찾으세요.

<Callout title="관리자 권한이 필요 없습니다">
설치는 내 계정 폴더와 바탕화면의 `ai-lab` 폴더에만 합니다. 이미 쓰던 다른 프로그램은 건드리지 않습니다.
</Callout>

</Step>

<Step id="prep-login" title="처음 실행하고 로그인하기">

열린 `ai-lab` 폴더에서 아래 파일을 **더블클릭** 합니다.

<ForTool tool="agy">

`start-agy.cmd` 를 실행하면 Antigravity CLI가 시작됩니다.

1. 로그인 방법을 물으면 **Google 계정** 로그인을 고릅니다.
2. 브라우저가 열리면 개인 Gmail로 로그인하고 허용합니다. 코드를 붙여넣으라고 하면 브라우저에 보이는 코드를 복사해 검은 창에 붙여넣습니다.
3. 화면 테마와 약관 동의를 차례로 고릅니다.
4. "이 폴더를 신뢰하나요?(Do you trust the contents of this project?)" 에는 **예** 를 고릅니다.

</ForTool>

<ForTool tool="codex">

`start-codex.cmd` 를 실행하면 Codex CLI가 시작됩니다.

1. 로그인 방법에서 **Sign in with ChatGPT** 를 고릅니다.
2. 브라우저가 열리면 ChatGPT 계정으로 로그인하고 허용합니다.
3. 이 폴더를 신뢰하는지 물으면 **신뢰(trust)** 를 고릅니다. 신뢰하지 않으면 읽기만 할 수 있어서 파일을 만들지 못합니다.

브라우저가 열리지 않으면 창을 닫고 cmd에서 `codex login --device-auth` 를 실행해 화면의 안내대로 코드를 입력하세요.

</ForTool>

<ForTool tool="claude">

`start-claude.cmd` 를 실행하면 Claude Code가 시작됩니다.

1. 화면 테마를 고릅니다.
2. 로그인 방법에서 **Claude 구독 계정** 을 고릅니다.
3. 브라우저가 열리면 claude.ai에 로그인하고 허용합니다.
4. "이 폴더를 신뢰하나요?" 에는 **Yes, I trust this folder** 를 고릅니다.

</ForTool>

화면 문구는 도구가 업데이트되면서 조금씩 달라질 수 있습니다. 로그인과 신뢰만 하면 됩니다.

</Step>

<Step id="prep-hello" title="AI에게 첫 인사 보내기">

입력창에 아래 문장을 붙여넣고 <kbd>Enter</kbd> 를 누릅니다.

<Prompt>{prompts.hello}</Prompt>

AI가 폴더 안의 `mission1`, `mission2`, `samples` 같은 폴더를 설명해 주면 준비 끝입니다. 창을 닫아도 됩니다.

</Step>

</Steps>

## bat 파일로 받은 경우

메신저나 메일로 `setup.bat` 파일을 받았다면 더블클릭해서 실행해도 됩니다. 인터넷에서 받은 파일이라 경고가 두 번 나옵니다.

1. **브라우저 경고**: "일반적으로 다운로드되지 않는 파일" 같은 경고가 나오면 **유지** 또는 **계속** 을 누릅니다.
2. **Windows 경고**: 파란 창 "Windows의 PC 보호" 가 나오면 **추가 정보** 를 누른 뒤 **실행** 을 누릅니다.

경고가 불안하면 위의 **한 줄로 설치하기** 를 쓰세요. 같은 파일을 받지만 경고가 나오지 않습니다.

## 설치 없이 점검만 하기

학교망이나 백신이 설치를 막는지 미리 알고 싶으면, 설치 프로그램에서 <kbd>4</kbd> 를 누르세요. 필요한 사이트에 접속되는지, PowerShell이 실행되는지 확인하고 결과만 보여 줍니다.
