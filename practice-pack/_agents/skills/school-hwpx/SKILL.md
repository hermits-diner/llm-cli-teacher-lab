# 학교 문서 양식(.hwpx) 채우기

양식 안의 `{{칸이름}}` 을 내용으로 바꿔 새 파일을 만듭니다. 원본 양식은 그대로 둡니다.
도구는 `tools/hwpx-fill.mjs` 하나만 씁니다(Node로 실행, 설치 불필요).

## 순서

1. 칸 목록을 봅니다.
   `node tools/hwpx-fill.mjs --list <양식.hwpx>`
2. 사용자가 준 메모(.txt)나 요청을 읽고, 칸마다 들어갈 문장을 정합니다.
3. 값 파일(JSON, UTF-8)을 **파일 쓰기 기능으로** 저장합니다. 키는 칸 이름입니다.
   ```json
   { "제목": "2학년 진로 현장체험학습 안내", "본문": "첫째 문장입니다.\n둘째 문장입니다." }
   ```
4. 채웁니다.
   `node tools/hwpx-fill.mjs <양식.hwpx> <값.json> <결과.hwpx>`
5. 출력에서 `"ok": true` 를 확인합니다.
   - `notFilledYet`: 아직 비어 있는 칸 → 값 파일에 추가
   - `keysNotInForm`: 양식에 없는 이름 → 이름을 `--list` 결과와 똑같이 고치기
   - `textCheckFailed`: 글자가 깨졌을 수 있음 → 값 파일을 UTF-8로 다시 저장
6. 결과를 글로 확인하고 사용자에게 요약해 줍니다.
   `node tools/hwpx-fill.mjs --text <결과.hwpx>`

## 문장 쓰는 법 (학교 문서)
- 가정통신문은 학부모께 드리는 공손한 문체(~합니다, ~주십시오)로 씁니다.
- 날짜에는 요일을 붙이고, 메모에 있는 날짜·요일을 그대로 씁니다. 메모에 없는 사실은 지어내지 않습니다.
- 한 칸이 너무 길면 `\n` 으로 줄을 나눕니다.
- 실제 학생 이름·연락처 같은 개인정보는 넣지 않습니다. 회신서처럼 학부모가 직접 쓰는 칸은 비워 둡니다.

## 하지 말 것
- `.hwpx` 를 직접 압축 해제하거나 XML을 고치기
- `echo '{...}' | node ...` 처럼 파이프로 JSON 넘기기 (Windows에서 한글이 깨집니다)
- Python 사용, 프로그램 설치
- 원본 양식 파일 덮어쓰기 (결과는 항상 새 이름으로)
- `samples/` 폴더의 완성 예시를 열어 보거나 문장을 가져다 쓰기 (메모를 바탕으로 새로 씁니다)
