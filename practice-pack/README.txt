LLM CLI 기반 수업자료제작 및 업무활용 — 실습 폴더 (바탕화면\ai-lab)

[시작하기]  내가 고른 도구의 파일을 더블클릭하세요.
  start-agy.cmd     Antigravity CLI
  start-codex.cmd   Codex CLI
  start-claude.cmd  Claude Code
  * AI가 매번 허락을 묻지 않고 바로 일합니다. 멈추려면 Esc.

[폴더 안내]
  mission2\          문서 작업: 한글 양식(.hwpx)과 메모(.txt). 이름 끝에 -h 가 붙은 것은 고등학교용
  mission1\site\     웹앱 제작: AI가 웹페이지(index.html)를 만들 곳
  samples\           완성 예시 (막혔을 때 보세요)
                       samples\mission2\notice-sample.hwpx  가정통신문 완성본
                       samples\mission1\  이 폴더를 Vercel에 올려 볼 수 있습니다
  slides\            슬라이드 제작: AI가 슬라이드(.pptx)를 만들 곳 (처음엔 없음)
  tools\             빈칸·슬라이드 검사 도구, Node.js와 Git (지우지 마세요)
  AGENTS.md          AI가 읽는 지침 (세 도구 공통)

[스킬]  한글(hwpx)·디자인(frontend-design) 스킬은 이 폴더가 아니라 사용자 폴더에 설치합니다.
        한 번 설치하면 다른 폴더에서도 쓸 수 있습니다.

[주의]
  - 학생 개인정보가 담긴 파일은 이 폴더에 넣지 마세요.
  - 모든 예시 내용은 연수용 가상 자료입니다.
